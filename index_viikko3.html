Week 3: Printing system status using Bash

A Bash script that reports the server's time, uptime, disk space and memory usage.

Commands used

date '+%-d.%-m.%Y klo %H.%M.%S'
Formats the report time as day, month, year and time. The script sets LC_TIME=fi_FI.UTF-8 for this command.
uptime -p
Shows how long the server has been running in a readable format.
df --output=pcent / | tail -n 1 | tr -dc '0-9'
Reads root filesystem usage. The pipes pass the output to tail to select the last line, then to tr to keep only digits for the disk status check.
free -h | awk '/^Mem:/ {print $2, $3, $7}'
Extracts total, used and available RAM from the memory row using human-readable units.

How the script works

system_stats.sh collects the current date, the server's timezone, uptime, root disk usage and RAM usage. It stores these values in variables and prints a compact report. The df -h commands provide free and total disk space; free -m and awk calculate the RAM usage percentage.

The disk_status function returns OK when disk usage is below 80% and WARNING at 80% or above. Exactly 80% already triggers the warning.

system_stats_viewer.sh runs the stats script and pipes its output through sed to remove terminal colour codes and escape HTML characters. It wraps the output in a <pre> element to preserve its spacing and line breaks. The iframe below displays that generated HTML.

Schedule and serving

Cron runs the viewer every minute with the schedule * * * * *.
